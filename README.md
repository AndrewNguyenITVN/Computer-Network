## 📘 Course Overview  
**Computer Networks (CT106H)** introduces fundamental concepts and technologies used in modern computer networks.  
The course focuses on understanding how data is transmitted, how protocols operate, and how devices communicate across the internet and local networks.

---

## 🔑 Main Topics Covered
- 📡 OSI and TCP/IP Models  
- 🧩 Network Devices: Hubs, Switches, Routers  
- 📦 Data Encapsulation and Packet Delivery  
- 🌍 IP Addressing and Subnetting  
- 📠 Routing and Switching Basics  
- 🔐 Network Protocols (ARP, ICMP, TCP, UDP, HTTP, etc.)  

---

## 📚 Learning Outcomes  
By the end of this course, students will be able to:
- Understand network architectures and protocol stacks  
- Analyze packet flow across networks  
- Perform IP subnetting and addressing  
- Describe the function of key networking devices  
- Explain how protocols like TCP, IP, and HTTP work
